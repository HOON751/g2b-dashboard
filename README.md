# 조달청 특정품목 조달내역 대시보드 — 실행 안내

## 📦 필요한 파일 (모두 같은 폴더 `g2b_dashboard`에 둘 것)
- `app.py`          ← 대시보드 메인
- `g2b_api.py`      ← API 호출 모듈
- `report.py`       ← 보고서 생성 모듈 (신규)
- `.env`            ← API 키 (이미 만들어 두신 것)

## 🔧 처음 한 번만: 패키지 설치
검은 창(명령 프롬프트)에서 `g2b_dashboard` 폴더로 이동한 뒤:

```
pip install streamlit pandas requests plotly python-dotenv openpyxl python-docx
```

보고서에 차트 이미지까지 넣고 싶으면 (선택):
```
pip install kaleido
```

## ▶️ 실행 방법
같은 폴더에서:

```
streamlit run app.py
```

엔터를 누르면 자동으로 웹 브라우저에 대시보드가 열려요.
(안 열리면 터미널에 표시되는 http://localhost:8501 주소를 직접 브라우저에 붙여넣으세요.)

## 🖱️ 사용법
1. 왼쪽 사이드바에서 **품목 검색 방식** 선택
   - 품명으로 검색: "합성목재" 또는 분류번호 "30103699"
   - 세부품명번호로 검색: "3010369901" 또는 "합성목재"
   - 물품규격명으로 검색: 식별번호 또는 규격명 일부
2. **기간** 설정 (최대 12개월)
3. 필요하면 **추가 필터** 펼쳐서 우수제품/수요기관/업체/지역 등 지정
4. **🔎 검색하기** 클릭
5. 7개 탭에서 결과 확인:
   - 🏢 업체별 매출 / 🏛️ 수요기관별 / 📈 기간별 추이
   - ⭐ 우수제품 비중 / 🗺️ 지역별 분포 / 📋 전체 내역(엑셀 다운로드)
   - 📝 **보고서**: 자동 분석 + 총평 + Word 다운로드

## ⏱️ 팁
- 데이터가 많은 품목(기간이 길수록)은 수집에 시간이 좀 걸려요. 진행 막대가 보여줘요.
- 종료하려면 터미널에서 Ctrl+C.

## ❓ 자주 나오는 문제
- **"서비스 접근 거부"(코드 20)**: 종합쇼핑몰 품목정보 서비스 활용신청 승인 확인
- **"요청 제한 초과"(코드 22)**: 일일 호출 한도 초과 → 내일 다시
- **빈 결과**: 검색어/기간을 바꿔보기
